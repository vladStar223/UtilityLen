# UtilityLens Mobile (Flutter) 📱

Мобильное приложение для интеллектуального аудита квитанций ЖКХ и юридической защиты жильцов (Владивосток / Приморский край).

Ветка: `feat/mobile-flutter`

---

## 🚀 Возможности приложения:
1. **Сканер квитанций и QR-кодов:** Наведение камеры на платежный QR-код ГОСТ Р 56042-2014 или загрузка из галереи.
2. **Факторный рентген (Детерминированное ядро):** Математическое разложение изменения чека:
   $$\Delta S = \Delta T (\text{тариф}) + \Delta V (\text{объем}) + \Delta R (\text{штрафы УК}) + \Delta N (\text{новые услуги})$$
3. **Детекция аномалий и нарушений:**
   * **Коэффициент 3.0 (Владивосток, ул. Амурская, д. 7):** Выявление незаконного начисления ХВС КГУП «Приморский водоканал» на **686.56 ₽ переплаты**.
   * Коэффициент 1.5 при пропуске поверки.
   * Зимний скачок отопления.
4. **ROI-калькулятор жителя:** Наглядный расчет сэкономленных денег (переплата + 3 500 ₽ за составление претензии юристом).
5. **Генератор досудебной претензии в 1 клик:** Готовое заявление в УК/Водоканал с ссылками на ст. 157 ЖК РФ и ПП РФ № 354 с кнопкой копирования и отправки.
6. **AI-Юрист со стримингом (SSE):** Онлайн-консультация по спорным начислениям.

## 🛠 Запуск и сборка:

### 1. Установка зависимостей:
```bash
cd mobile
flutter pub get
```

### 2. Запуск на эмуляторе или подключенном телефоне:
```bash
flutter run
```

### 3. Сборка APK для демонстрации на хакатоне:
```bash
flutter build apk --release
# Готовый файл появится в: build/app/outputs/flutter-apk/app-release.apk
```
