- **СТРОГО ЗАПРЕЩЕНО:**
  - Менять файлы в `backend/**` и `contracts/**`.
  - Менять имена полей контракта. Все данные должны строго соответствовать `contracts/compare_response.json`.

---

## 📝 Список задач (Backlog)

1. **Адаптер данных с Mock-режимом (`web/api_client.py`):**
   - Переменная окружения `USE_MOCK_API`:
     - Если `USE_MOCK_API=true` (значение по умолчанию при локальной верстке): клиент читает `contracts/compare_response.json` и список кейсов из `data/cases/`.
     - Если `USE_MOCK_API=false`: клиент делает реальные HTTP-запросы (`httpx` / `requests`) к FastAPI (`API_BASE_URL`).
   - Методы: `get_cases()`, `compare_bills(case_id)`, `send_chat_message(comparison_id, message)`.

2. **Боковая панель (`web/components/sidebar.py`):**
   - Выпадающий список демо-сценариев (например: *«Кейс 2: Штрафной коэффициент 1.5»*).
   - Переключатель: **«Демо-кейсы (1 клик)»** vs **«Загрузка своих файлов (PDF/JSON)»**.
   - Кнопка *«Сравнить квитанции»*.

3. **Экран аналитики (`web/components/dashboard.py`):**
   - **KPI карточки светофора:**
     - Сумма к оплате (`curr_total`).
     - Разница с прошлым месяцем в ₽ (`delta_abs`) и % (`delta_pct`).
     - Главный драйвер роста: сравнение `tariff_effect_rub` vs `volume_effect_rub`.
     - Бейдж верификации QR: зеленый щит `Проверено по ГОСТ QR` или красный `Расхождение с QR`.
   - **Блок «Красные флаги» (`anomalies`):**
     - Выделенные плашки предупреждений с бейджем степени критичности (`red` / `yellow`).
     - Подсветка суммы переплаты (`impact_rub`).
     - Кнопка *«Задать вопрос юристу»* (подставляет готовый вопрос в чат).
   - **График факторного анализа (Plotly):**
     - Водопадная (Waterfall) или горизонтальная столбчатая диаграмма:
       - Базовый счет прошлого месяца
       - + Рост тарифа
       - + Рост объема потребления
       - + Перерасчеты и штрафы
       - = Итоговый счет текущего месяца
   - **Таблица услуг «Было / Стало»:**
     - Столбцы: Услуга, Ед. изм., Расход (было/стало), Тариф (было/стало), Итого (было/стало), Разница, Пояснение.
     - Цветовая маркировка строк по статусу (`status`: green, yellow, red).

4. **Виджет чата с AI-юристом (`web/components/chat.py`):**
   - Интерактивное диалоговое окно (st.chat_message).
   - Поддержка стриминга SSE-ответа.
   - Быстрые подсказки-кнопки над полем ввода:
     - ❓ *«Почему выросла общая сумма?»*
     - ⚖️ *«Законно ли начисление коэффициента 1.5?»*
     - 📄 *«Составь текст претензии в управляющую компанию»*

5. **Точка входа (`web/app.py`):**
   - Инициализация темы Streamlit (аккуратный дизайн, кастомный CSS при необходимости).
   - Сборка компонентов воедино.

---

## ✅ Критерий приемки (Definition of Done)
1. Приложение успешно стартует командой:
   ```bash
   USE_MOCK_API=true streamlit run web/app.py
   ```
2. Все 4 компонента (KPI, Аномалии, График Plotly, Таблица услуг, Чат) корректно отрисовываются на данных `contracts/compare_response.json`.
3. При переключении `USE_MOCK_API=false` приложение прозрачно переключается на сетевой бэкенд без ошибок в коде UI.
