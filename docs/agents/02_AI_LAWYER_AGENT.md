## 📝 Список задач (Backlog)

1. **Инструменты агента (`backend/app/agent/tools.py`):**
   - `lookup_glossary(term: str)`: поиск определений терминов, ссылок на статьи Постановления Правительства РФ № 354 в базе знаний `data/knowledge_base/glossary.json`.
   - `get_anomaly_action_plan(anomaly_code: str)`: извлечение проверенного пошагового алгоритма действий (например, для `APPLYING_COEFF_1_5`, `SOI_SPIKE`).
   - `draft_uk_claim(comparison_id: str, anomaly_code: str)`: генерация юридически грамотной претензии в управляющую компанию / ГЖИ с подстановкой точных сумм ущерба и реквизитов из отчета.

2. **Оркестрация и системный промпт (`backend/app/agent/runner.py`):**
   - **Системный промпт:**
     - Роль: опытный юрист по жилищному праву РФ.
     - Стиль: спокойный, деловой, понятный человеку без юридического образования.
     - Обязательно давать ссылки на конкретные пункты ПП РФ № 354 и Жилищного кодекса РФ.
     - Категорически запрещено галлюцинировать суммами: все суммы берутся из переданного JSON.
   - **Потоковый генератор (SSE):**
     - Формат: `text/event-stream`.
     - События: `data: {"type": "token", "content": "..."}\n\n` и `data: {"type": "done"}\n\n`.
     - Индикация вызова инструментов: `data: {"type": "tool_call", "name": "lookup_glossary"}\n\n`.

3. **API Роут (`backend/app/api/chat.py`):**
   - Эндпоинт `POST /api/v1/chat/stream`.
   - Принимает `{comparison_id, message, history}`.
   - Возвращает StreamingResponse (SSE).

4. **Автотесты (`backend/tests/test_agent.py`):**
   - Тест на вызов тулов `lookup_glossary` и `get_anomaly_action_plan`.
   - Тест сценария: при передаче отчета с аномалией `APPLYING_COEFF_1_5` агент в ответе называет точную сумму переплаты 245.18 ₽ и статью п. 60(1) ПП РФ № 354.

2. При стриминге ответа через SSE фронтенд без задержек получает чанки текста и валидный статус завершения.
3. Ни в одном тестовом диалоге агент не изменяет и не перевирает суммы из `ComparisonReport`.
